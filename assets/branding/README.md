# MW4 Remastered launcher mark

`mw4-remastered-master.png` is the selected project-owned RGBA master. `MW4-Remastered.ico` is its 256×256 Windows application-icon packaging and is compiled into the launcher.

The mark was generated with the built-in image-generation tool, using the prior MW3 remaster icon only as a badge-placement reference and the local original-game icons only as compact-silhouette references. It is an original heavy-mech/`4` composition with a distinct lower-right `R`, not a traced franchise logo or copied web asset.

Final prompt summary: simplify an original front-facing heavy battle-mech and integrated numeral `4` into a bold industrial silhouette; retain near-black/gunmetal, amber, and pale-steel colors; enlarge the lower-right capital `R`; use a genuinely transparent background; avoid franchise wordmarks, extra text, fine texture, mockups, and watermarks.
