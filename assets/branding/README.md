# MW4 Remastered launcher mark

`mw4-remastered-master.png` is the selected 512×512 nearest-neighbor preview master. `MW4-Remastered.ico` is its 256×256 RGBA Windows application-icon packaging and is compiled into the launcher.

The base is the user-provided 32×32-derived MechWarrior 4: Vengeance icon preview. The only intentional artwork change is the remaster badge: the exact non-black 6×7 silver/gray `R` glyph pixels at `(25,23)` were isolated from the installed MW3 Remastered launcher icon and composited onto the MW4 icon's native 32×32 grid. The 512×512 preview and 256×256 ICO use nearest-neighbor scaling so the original pixel texture is not smoothed or reinvented.

The base artwork is not claimed as project-owned. Its redistribution status must be resolved with the other original-game assets before a public release payload is approved.
