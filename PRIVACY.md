# Privacy

MechWarrior 4 Remastered is a local Windows installer and launcher. It does not include analytics, advertising, accounts, or telemetry and does not upload your media, saves, configuration, or diagnostics.

Setup and the launcher may store installed-game files derived from media you select, ownership manifests used for repair and safe uninstall, original game registration values, user configuration and saves, and a local installation log.

Multiplayer remains the original games' networking behavior. If selected during setup, the installer creates narrowly named Windows Firewall rules for the exact installed game executables: allow on Private networks and block on Public networks. It does not enable broad inbound access.

Review and redact logs before sharing them because local filesystem paths may identify your Windows account or folder layout.
